# SticsREval
Evaluate STICS performance 


## Installation

### Basic installation

The package can be installed from Github using either `devtools` or the lightweight `remote` package.
The latest release version can be installed using:

* With `devtools`
```R
devtools::install_github("SticsRPacks/SticsREval@*release")
```

* With `remotes`
```R
remotes::install_github("SticsRPacks/SticREval@*release")
```

Normally, all the package dependencies will be installed from CRAN packages.
