# Changelog

## SticsREval (development version)

- New
  [`plot_rrmse_comparison()`](https://sticsrpacks.github.io/SticsREval/reference/plot_rrmse_comparison.md)
  function to plot the rRMSE of the evaluated version against the
  reference version, one point per variable, coloured by regression
  status ([\#69](https://github.com/SticsRPacks/SticsREval/issues/69)).
- The Quarto report generated by
  [`render_report()`](https://sticsrpacks.github.io/SticsREval/reference/render_report.md)
  has been refactored and cleaned up
  ([\#68](https://github.com/SticsRPacks/SticsREval/issues/68)).

## SticsREval 0.1.1

- The rRMSE comparison plots are now shown in the HTML report
  ([\#66](https://github.com/SticsRPacks/SticsREval/issues/66)).
- The minimum number of observations criterion (`n_obs >= 10`) is now
  applied consistently across the global, species and USM evaluations
  ([\#65](https://github.com/SticsRPacks/SticsREval/issues/65)).

## SticsREval 0.1.0

- First tagged release.
- [`evaluate()`](https://sticsrpacks.github.io/SticsREval/reference/evaluate.md)
  runs the global, per-species and per-USM statistical evaluations of a
  STICS version against field observations and against a reference
  version.
- [`balance_closure_test()`](https://sticsrpacks.github.io/SticsREval/reference/balance_closure_test.md)
  checks water and nitrogen balance closure for each USM.
- [`gen_workspace_from_sms()`](https://sticsrpacks.github.io/SticsREval/reference/gen_workspace_from_sms.md)
  builds a STICS text workspace from a raw SMS repository, and
  [`run_simulations()`](https://sticsrpacks.github.io/SticsREval/reference/run_simulations.md)
  runs STICS on it and saves the simulation and observation data as RDS
  files.
- [`render_report()`](https://sticsrpacks.github.io/SticsREval/reference/render_report.md)
  renders the evaluation results as a browsable HTML dashboard.
- A Docker image bundling the package, its dependencies and the Quarto
  CLI is published on the GitHub Container Registry.
