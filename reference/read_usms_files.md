# Read one or more USM list files.

Read one or more USM list files.

## Usage

``` r
read_usms_files(usms_files)
```

## Arguments

- usms_files:

  character vector of one or more paths to text files, each containing
  one USM name per line (e.g. the output of `get_usms_files.R`)

## Value

a character vector of unique USM names
