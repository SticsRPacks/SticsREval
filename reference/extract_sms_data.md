# Extract all necessary files from SMS and copy it to a destination directory.

Extract all necessary files from SMS and copy it to a destination
directory.

## Usage

``` r
extract_sms_data(sms_path, stics_path, destination_dir)
```

## Arguments

- sms_path:

  path to the SMS repository

- stics_path:

  path to Stics repository

- destination_dir:

  path where the files must be copied
